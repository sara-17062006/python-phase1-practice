# Python Phase 1 Placement Practice

54-question Python placement practice app with browser execution, autosave, and AI final review.

## Features
- 54 Phase 1 problems
- Run Python in the browser with Pyodide
- Save code/input/progress in local storage
- Final Review sends all 54 submissions to /api/review
- API key stays server-side in Vercel

## Vercel environment variables
- OPENAI_API_KEY
- OPENAI_MODEL

Never put the API key in the frontend or commit it to GitHub.

## Deployment
Import this repository into Vercel and add the two environment variables before using FINAL REVIEW.
