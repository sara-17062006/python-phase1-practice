17. Searching

# linear search found = False for x in arr: if x == target: found = True break # binary search on sorted array l, r = 0, len(arr) - 1 while l <= r: m = (l + r) // 2 if arr[m] == target: break elif arr[m] < target: l = m + 1 else: r = m - 1
Linear search: O(n). Binary search: O(log n), but the data must be ordered or the search condition must be monotonic.

24. Edge Cases & Debugging Checklist

Before submitting, test: 1. Smallest valid input 2. Largest valid input 3. 0 4. Negative values (when allowed) 5. Duplicate values 6. Equal values 7. Empty string / empty list (when allowed) 8. One-element input 9. Boundary values like 1, 2, 99, 100 10. Sample + one custom case
Your personal focus from Phase 1: boundary conditions, zero-handling, and checking whether your logic matches the English requirement—not only the sample.

25. Placement Problem-Solving Method

STEP 1 → Understand the input STEP 2 → Identify what must be printed STEP 3 → Write 1–2 manual examples STEP 4 → Find the repeating logic STEP 5 → Choose the simplest data structure STEP 6 → Code STEP 7 → Dry run with a new input STEP 8 → Check edge cases STEP 9 → Think about time / space STEP 10 → Explain your solution aloud
Do not memorize only the final code. Train yourself to explain: input → idea → steps → complexity → edge cases → output.
